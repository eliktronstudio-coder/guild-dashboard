# GPT Vision в существующем боте XD

Состав и дроп читает OpenAI Responses API, `gpt-5.4-mini`, изображения `detail: original`. Tesseract не вызывается и не является резервным режимом. Рабочая точка входа импортирует только обработку изображений без subprocess/OCR; установщик бота не требует локальных языковых моделей. Старые утилиты локального OCR оставлены в репозитории для исторических тестов и не подключены к работающему боту.

## Состав

Оригинал и увеличенные цветные ячейки передаются GPT. Если локальный анализ геометрии не выделил состав, отправляется оригинал и увеличенная копия. Каталог игроков модели не передаётся: прочитанные ники локально сопоставляются с существующим `/api/discord/context`. Исходное чтение, выбранный игрок, номер группы и ручные исправления хранятся отдельно. Неоднозначные/обрезанные ники остаются на проверке; память ников, гости и ручное добавление/удаление работают в прежнем черновике. Повторное чтение спорных ников отправляет только выделенные фрагменты.

## Дроп

Первый скрин — состав, остальные — дроп. Каждый скрин дропа получает отдельный GPT-разбор. Ответ — строгий JSON с отдельной строкой на каждое вхождение: название, количество и признак сомнения. Одинаковые названия не схлопываются до выбора точного предмета. В строке «Получено» отсутствие множителя означает 1; явные x/х/× количества читаются отдельно от размера набора в названии. Нечитаемое количество возвращается как null, неоднозначное название требует проверки.

Сопоставление и поиск используют действующий реестр сайта. Для «Эссенции ярости» без размера предлагаются ×1000, ×2000 и остальные варианты из реестра; количество наборов подтверждается отдельно. После выбора одинаковые реальные ID суммируются. Ручное исправление, пропуск шума, добавление предметов и текстовый редактор сохранены. При добавлении следующих скринов ручные исправления и уже прочитанные изображения сохраняются.

## Недоступность GPT

При ошибке ключа, региона, квоты, лимита или тайм-аута бот не переходит на локальное распознавание. Он сообщает безопасную причину и предлагает повторить GPT-разбор или ввести данные вручную. Неудачно прочитанный скрин не помечается успешно обработанным. Ошибка чтения дропа создаёт спорную строку и не превращается незаметно в «дропа нет». Старая кнопка бесплатного OCR отклоняется без платного запроса. Перед публикацией остаётся подтверждение состава и дропа; кнопка сохранения активна и поясняет недостающие проверки.

## Подключение

Бот на Timeweb читает `/etc/xd-discord-bot.env` через существующий systemd unit `xd-discord-bot.service`. Состояние и постоянный бюджет — `/var/lib/xd-discord-bot/drafts.sqlite`. Сайт/канал/Discord token настраиваются как раньше в `/admin/discord`.

В удалённом режиме `VISION_SERVICE_URL` и `VISION_SERVICE_SECRET` соединяют worker с существующим сервисом Render. `OPENAI_API_KEY` требуется только в окружении Render, где уже настроен ключ. Ключ OpenAI не передаётся в запросах worker. Без удалённого сервиса прямой режим получает ключ исключительно из `process.env.OPENAI_API_KEY` на worker. Секреты не добавляются в GitHub, исходный код и отчёты.

Сервис поддерживает подписанные `/v1/roster` и `/v1/loot`. Старый протокол состава совместим с обновлённым сервисом. Публичный `/health` сообщает `loot-vision-v1` и `gpt-only`; защищённый `/ready` проверяет только доступность модели без платного распознавания. Старый Claude proxy не меняется.

## Бюджет

Общий постоянный лимит состава и дропа — $5 в месяц, не более двух одновременных запросов. Суточный лимит отключён (`OPENAI_DAILY_LIMIT=unlimited`), его можно задать числом. Нормализованные пиксели и тип разбора участвуют в ключе кэша; идентичные изображения повторно не оплачиваются. Дроп и состав одного изображения имеют разные ключи. Каждый новый скрин дропа теперь тоже использует GPT API.

Перед запросом резервируется верхняя оценка стоимости; после ответа учитываются реальные `input_tokens` и `output_tokens` по $0.75/$4.50 за миллион. При неизвестном usage резерв остаётся консервативно списанным. Учёт переживает рестарты. Логи содержат только код ошибки, модель, токены и оценку стоимости. Render дополнительно ограничивает параллельность и бюджет в памяти; основной общий лимит хранится на Timeweb.

Поддерживаются `OPENAI_MODEL`, `OPENAI_TIMEOUT_MS`, `OPENAI_MAX_OUTPUT_TOKENS`, `OPENAI_DAILY_LIMIT`, `OPENAI_CONCURRENCY`, `OPENAI_MONTHLY_BUDGET_USD`, `OPENAI_CACHE_DAYS`, `OPENAI_BUDGET_TIMEZONE`. В удалённом режиме тайм-аут по умолчанию 120 секунд для пробуждения Free Render. Код не перезаписывает окружение или существующие секреты.

## Проверки

`npm test --prefix apps/discord-bot` и `npm test --prefix apps/vision-service` используют имитации OpenAI, без платных запросов. Проверяются оригиналы/увеличения, кэш, общий бюджет, подпись/авторизация, некорректный JSON, тайм-ауты, сохранение отдельных вхождений и независимый выбор размера/количества наборов. Реальные платные проверки требуют отдельного разрешения.
