# GPT Vision в существующем боте XD

Основной разбор состава — OpenAI Responses API, `gpt-5.4-mini`, изображения `detail: original`. Оригинал передаётся вместе с увеличенными цветными ячейками. Каталог игроков не передаётся модели: точные имена и зарегистрированные альтернативные персонажи сопоставляются локально с `/api/discord/context`. Неоднозначные, похожие и обрезанные ники требуют ручного подтверждения. Сохраняются исходное чтение, группа, выбранный ник и ID игрока. Дроп продолжает обрабатывать существующий Tesseract. Если ячейки интерфейса не выделены, используется Tesseract.

Без ключа и при ошибках/лимитах работает Tesseract. В существующем импорте доступны «Tesseract бесплатно» и «Перечитать спорные GPT». Повторный анализ отправляет только спорные ячейки; ручные исправления, игнорирование шума и дроп сохраняются. После любого разбора проверяйте состав перед публикацией.

## Подключение на Timeweb

Существующий `xd-discord-bot.service` использует `EnvironmentFile=/etc/xd-discord-bot.env`. Откройте файл через `sudoedit /etc/xd-discord-bot.env`, сохраняя все существующие строки. Добавьте или обновите **только**:

```dotenv
OPENAI_API_KEY=<секретный ключ из OpenAI Platform>
OPENAI_MODEL=gpt-5.4-mini
```

Не присылайте ключ в чат, не добавляйте в GitHub или настройки фронтенда. Рекомендуется отдельный OpenAI project с ограниченным бюджетом. ChatGPT-подписка не предоставляет API-кредиты. Создайте API project, подключите оплату и создайте project API key в https://platform.openai.com/api-keys.

После сохранения:

```sh
sudo chmod 600 /etc/xd-discord-bot.env
sudo systemctl restart xd-discord-bot.service
sudo systemctl is-active xd-discord-bot.service
```

Код не перезаписывает env-файл. Схема автодеплоя не меняется. Панель Discord/канала остаётся на https://xd-guild.ru/admin/discord; ключ GPT задаётся исключительно на VPS.

## Локальные ограничения

Параметры перечислены в `.env.example`. По умолчанию: 20 попыток запросов в сутки, 2 одновременно, месячный предел $5, таймаут 60 секунд, без автоматических повторов SDK. Суточная/месячная граница — Asia/Yekaterinburg. Можно уменьшить бюджет; значение выше $5 отклоняется. Нулевой бюджет или дневной лимит отключает платные вызовы.

SQLite `/var/lib/xd-discord-bot/drafts.sqlite` содержит учёт запросов и кэш чтения (30 дней, максимум 500 изображений). Ключ кэша зависит от нормализованных исходных пикселей, модели, версии инструкции, сервера и выбранных фрагментов. Исходные изображения и API-ключ в эти таблицы не записываются. Кэш хранит чтение, а не готовые привязки аккаунтов: каталог проверяется заново.

Перед вызовом резервируется верхняя оценка стоимости: 400000 входных токенов по $0.75/млн + лимит выходных токенов по $4.50/млн. После ответа резерв заменяется фактическим usage, без скидки за cached input (консервативно). При потере ответа/неизвестном usage резерв остаётся списанным; поэтому лимит может остановить GPT раньше $5. Явный отказ API (например 401/429) снимает денежный резерв, но учитывает попытку в суточном лимите. Учёт сохраняется после перезапуска, охватывает все серверы этого экземпляра и не контролирует другие приложения, использующие тот же OpenAI project. В логах — только безопасный код ошибки, токены, модель и оценка стоимости.

## Проверка без расходов

`npm test` использует исключительно имитации OpenAI. Тесты проверяют исходные изображения, structured output, кэш, лимиты/конкурентность, ошибки, спорные фрагменты, точные ID и ручную проверку. Реальное качество и доступность модели проверяются отдельным разрешённым запуском после установки ключа.
