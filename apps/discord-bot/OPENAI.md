# GPT Vision в существующем боте XD

Основной разбор состава — OpenAI Responses API, `gpt-5.4-mini`, изображения `detail: original`. Оригинал передаётся вместе с увеличенными цветными ячейками. Каталог игроков не передаётся модели: точные имена и зарегистрированные альтернативные персонажи сопоставляются локально с `/api/discord/context`. Неоднозначные, похожие и обрезанные ники требуют ручного подтверждения. Сохраняются исходное чтение, группа, выбранный ник и ID игрока. Дроп продолжает обрабатывать существующий Tesseract. Если локальный детектор не выделил ячейки, GPT получает исходный скриншот и сам находит надписи состава. Этот режим использует те же суточные/месячные лимиты, очередь и кэш. Все имена из такого разбора требуют ручного подтверждения; у них нет выдуманных координат и кнопка платного перечитывания отдельных фрагментов недоступна. При отсутствии ников GPT возвращает пустой список вместо шума из интерфейса. Обычный разбор выделенных ячеек и Tesseract остаются доступными.

Без ключа и при ошибках/лимитах работает Tesseract. В существующем импорте доступны «Tesseract бесплатно» и «Перечитать спорные GPT». Повторный анализ отправляет только спорные ячейки; ручные исправления, игнорирование шума и дроп сохраняются. После любого разбора проверяйте состав перед публикацией.

## Подключение на Timeweb

Существующий `xd-discord-bot.service` использует `EnvironmentFile=/etc/xd-discord-bot.env`. Откройте файл через `sudoedit /etc/xd-discord-bot.env`, сохраняя все существующие строки. Добавьте или обновите **только**:

```dotenv
OPENAI_API_KEY=<секретный ключ из OpenAI Platform>
OPENAI_MODEL=gpt-5.4-mini
```

Не присылайте ключ в чат, не добавляйте в GitHub или настройки фронтенда. Рекомендуется отдельный OpenAI project с ограниченным бюджетом. ChatGPT-подписка не предоставляет API-кредиты. Создайте API project, подключите оплату и создайте project API key в https://platform.openai.com/api-keys.

После сохранения:

```sh
sudo chmod 600 /etc/xd-discord-bot.env
sudo systemctl restart xd-discord-bot.service
sudo systemctl is-active xd-discord-bot.service
```

Код не перезаписывает env-файл. Схема автодеплоя не меняется. Панель Discord/канала остаётся на https://xd-guild.ru/admin/discord; ключ GPT задаётся исключительно на VPS.

## Локальные ограничения

Параметры перечислены в `.env.example`. По умолчанию: 20 попыток запросов в сутки, 2 одновременно, месячный предел $5, таймаут 60 секунд, без автоматических повторов SDK. Суточная/месячная граница — Asia/Yekaterinburg. Можно уменьшить бюджет; значение выше $5 отклоняется. Нулевой бюджет или дневной лимит отключает платные вызовы.

SQLite `/var/lib/xd-discord-bot/drafts.sqlite` содержит учёт запросов и кэш чтения (30 дней, максимум 500 изображений). Ключ кэша зависит от нормализованных исходных пикселей, модели, версии инструкции, сервера и выбранных фрагментов. Исходные изображения и API-ключ в эти таблицы не записываются. Кэш хранит чтение, а не готовые привязки аккаунтов: каталог проверяется заново.

Перед вызовом резервируется верхняя оценка стоимости: 400000 входных токенов по $0.75/млн + лимит выходных токенов по $4.50/млн. После ответа резерв заменяется фактическим usage, без скидки за cached input (консервативно). При потере ответа/неизвестном usage резерв остаётся списанным; поэтому лимит может остановить GPT раньше $5. Явный отказ API (например 401/429) снимает денежный резерв, но учитывает попытку в суточном лимите. Учёт сохраняется после перезапуска, охватывает все серверы этого экземпляра и не контролирует другие приложения, использующие тот же OpenAI project. В логах — только безопасный код ошибки, токены, модель и оценка стоимости.

## Проверка без расходов

`npm test` использует исключительно имитации OpenAI. Тесты проверяют исходные изображения, structured output, кэш, лимиты/конкурентность, ошибки, спорные фрагменты, точные ID и ручную проверку. Реальное качество и доступность модели проверяются отдельным разрешённым запуском после установки ключа.

## Отказ OpenAI по региону (403)

`unsupported_country_region_territory` означает региональное ограничение доступа к OpenAI. Замена OCR-настроек или повторная отправка того же скриншота не исправит такой отказ. Бот показывает причину и использует Tesseract; автоматических повторов нет.

Для GPT необходимо разрешённое OpenAI размещение и доступный API-проект. Можно перенести **только Discord-worker** на подходящий VPS, оставив сайт и базу на текущем сервере: бот использует существующий защищённый HTTPS API `https://xd-guild.ru/api/discord/`. Проверьте поддержку страны у OpenAI перед выбором региона хостинга. Секреты переносятся безопасно в `/etc/xd-discord-bot.env`, а SQLite с памятью ников и бюджетом — в `/var/lib/xd-discord-bot`. Старый экземпляр должен быть остановлен перед запуском нового, чтобы не было двух обработчиков и двух независимых бюджетов. Платный тест требует отдельного разрешения.

## Выделенный обработчик Render

`VISION_SERVICE_URL=https://<имя-сервиса>.onrender.com` и `VISION_SERVICE_SECRET` переключают существующий модуль на `apps/vision-service`. В этом режиме ключ OpenAI нужен **только на Render**; наличие или ошибки сервиса никогда не приводят к прямому запросу OpenAI с VPS. Общие prompt/schema используются обоими режимами. Ответы по-прежнему проходят проверку и сопоставление на Timeweb. Изображения отправляются по HTTPS в подписанном запросе; URL внешних картинок, произвольные промпты и модели не принимаются. Ники и API-ключ в журналы не записываются.

SQLite с постоянным кэшем и основным бюджетом остаётся на Timeweb. Render дополнительно ограничивает параллельность, попытки и стоимость в памяти процесса; эти дополнительные счётчики и 10-минутный кэш повторов сбрасываются при его перезапуске. Постоянные лимиты Timeweb при этом сохраняются. Бесплатный Render может засыпать: таймаут удалённого режима по умолчанию 120 секунд, максимально 180 секунд. При сбое сервис не повторяет OpenAI-запрос, бот переходит на Tesseract.

Проверки `/health` и защищённый `/ready` не запускают распознавание. `/ready` проверяет только метаданные модели, без платной генерации. Полноценный платный разбор для тестирования требует отдельного разрешения.
