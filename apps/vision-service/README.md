# XD GPT Vision service

Небольшой обработчик для существующего Discord-worker. Использует официальный OpenAI SDK и Responses API, фиксированный протокол чтения ячеек рейда. Сайт и Discord-соединение остаются на Timeweb. Старый `guild-vision-proxy` с Claude можно сохранить отдельно.

Render Web Service, Node 24, Oregon, тариф **Free**:

| Поле | Значение |
|---|---|
| Repository | `eliktronstudio-coder/guild-dashboard` |
| Branch | `codex/xd-foundation-20261031` |
| Root Directory | пусто |
| Build Command | `npm ci --prefix apps/vision-service` |
| Start Command | `node apps/vision-service/src/index.mjs` |
| Health Check | `/health` |

Переменные только в настройках Render: `OPENAI_API_KEY`, `OPENAI_MODEL=gpt-5.4-mini`, `VISION_SERVICE_SECRET` (случайный секрет не короче 32 символов), `NODE_VERSION=24`. Порт задаёт Render. Тот же сервисный секрет и URL нужны существующему боту в `/etc/xd-discord-bot.env`. Сам ключ OpenAI после проверки Render следует убрать из окружения VPS.

`POST /v1/roster` принимает только PNG data URL, номера ячеек, утверждённую модель и лимит ответа; проверяет отдельный Bearer-секрет и HMAC тела с временной меткой. Запрос ограничен 24 МБ. Произвольные промпты/URL не поддерживаются. Повтор с тем же идентификатором и телом получает прежний ответ; изменённое тело с тем же идентификатором отклоняется. Максимум 2 одновременных запроса. Ошибки возвращаются без текста SDK и содержимого скриншотов.

`GET /health` — проверка процесса. `GET /ready` требует сервисного секрета и проверяет только доступность метаданных модели. Это не платное распознавание и не проверка баланса API. `npm test` работает с имитациями, без реальных запросов к OpenAI.

Основной постоянный бюджет и кэш находятся в SQLite бота на Timeweb. Дополнительные предохранители Render (20 попыток/день, $5/месяц, 2 одновременно) и кэш повторов на 10 минут — в памяти, не заменяют постоянный учёт Timeweb. Free-инстанс может засыпать, поэтому первый разбор может ждать около минуты или дольше. Лимит бесплатных часов Render общий для аккаунта; платный тариф автоматически не подключается.
