# XD Guild Command Center — полный чек-лист

Состояние дизайн-чек-листа на 2026-10-31. **Позднейшее решение владельца: дизайн отложен; начата реализация основы. Точный прогресс кода и проверок — [STAGE1.md](docs/STAGE1.md). Ниже полный объём будущей платформы, отметки не являются автоматической приёмкой нового кода.** Основа: master prompt 1.1 и последующие решения владельца. XD / ХД — одна гильдия в ArcheAge.

`[x]` означает, что выполнено именно написанное действие: утверждён выбор, подготовлен материал или проведена указанная проверка. Утверждённый дизайн не означает реализованную функцию. `[ ]` — работа или решение ещё впереди. Метка **Выбор** обозначает вопрос владельцу; остальные пункты выполняет команда. Все ответы сразу не требуются: решения принимаются перед соответствующим этапом. Для ответа с телефона достаточно кода пункта, например `LOG-01: кицунэ`, `NAV-02: нижнее меню`.

Полный список задаёт объём конечной платформы. Он не запускает реализацию всех модулей одновременно и не расширяет первый релиз без отдельного решения.

Для удобства ответы владельца вынесены в [отдельный список решений](docs/OWNER_CHECKLIST.md). Полный чек-лист содержит 273 пункта; отметки готовности относятся к названному действию, а не к проценту готовности приложения.
