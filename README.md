# XD Guild Command Center

Платформа одной игровой гильдии XD / ХД. Japanese Dark Fantasy. Некоммерческий проект.

**Состояние: созданы основа и первый модуль состава; облачное подключение в процессе.** По указанию владельца дизайн отложен; B0, S1 и F1 сохранены. Создано отдельное приложение [apps/web](apps/web) с авторизацией через Supabase, обязательным ником, заявками, одобрением, ролями и RLS. Добавлены профили, основной и дополнительные персонажи, история ников, фильтры и мобильные карточки состава. Код проверен локально; реальная база, OAuth/SMTP и деплой ещё не подключены. Старое Express-приложение сохранено.

## Запуск новой версии

```sh
cd apps/web
npm ci
cp .env.example .env.local
npm run dev
```

Без настроек вход честно выключен. Для подключения с телефона: **[SETUP.md](docs/SETUP.md)**. Что сделано и проверено: **[STAGE1.md](docs/STAGE1.md)** и **[STAGE2.md](docs/STAGE2.md)**. `npm run check` внутри `apps/web` запускает TypeScript, PostgreSQL/RLS-тесты и production-сборку.

## Посмотреть концепцию

Откройте `docs/concept/index.html` в браузере: автономный макет без сборки, сетевых запросов и сохранения данных. Концепция 02: фотореалистичные изображения, лёгкое движение фона и переходы между экранами, кнопка отключения анимаций. Переключаются две темы и экраны обзора, входа, заявки и состава. Все примеры обозначены как демонстрационные. На телефоне навигация переносится вниз.

При необходимости локального просмотра: `python -m http.server 4173 --bind 127.0.0.1 --directory docs/concept`, затем `http://127.0.0.1:4173`. Это только сервер макета.

## Предлагаемый первый запуск

Этап 1: оформление, Telegram-вход, обязательный игровой ник, согласия, заявка, рассмотрение, роли, блокировка и личный кабинет. Этап 2: состав с поиском, профили и персонажи. Вместе это минимальная полезная версия для реального использования. Уведомления бота, финансовый учёт и расширенные графики — следующие независимые этапы.

Email/пароль предусмотрен требованиями; включается после настройки SMTP и проверки доставки, подтверждения адреса и восстановления. Его отсрочка в первом релизе — предложение для согласования, а не изменение согласованных требований.

## Существующее приложение

Express + PostgreSQL, запуск `npm start`, Node >=20 по текущему package.json. Требует существующих настроек `DATABASE_URL`, `SESSION_SECRET`, `GUILD_SHEET_ID`. Секреты не хранить в Git. Текущее приложение здесь не запускалось и его внешние данные не проверялись. Инструкции новой платформы находятся в docs/SETUP.md; root directory для её деплоя — apps/web.
