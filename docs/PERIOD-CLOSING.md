# Закрытие периода

Раздел `/archive` работает с реальными данными Supabase. Закрытие доступно владельцу, администратору и гильд мастеру с 14-го числа по Екатеринбургу. Период — с 15-го до следующего 15-го, исключая верхнюю границу (существующие расчёты используют UTC). Закрытие 14-го — явная финальная фиксация: после неё дополнительные рейды в этом диапазоне недоступны. С 15-го новый период выбирается автоматически.

Перед закрытием разбираются заявки участников. Подпись расчёта защищает от фиксации устаревшей страницы; блокировка гильдии сериализует расчёт и финансовые операции. Повторное закрытие возвращает тот же архив.

Общая посещаемость >=20%, вес посещённых активностей × личный коэффициент. Уже проведённые выплаты сохраняются. Закрытие распределяет всю свободную выручку существующим алгоритмом точных долей, не регистрируя передачу золота. Неизменяемый снимок хранит состав, проценты, коэффициенты, суммы, активности с отметками, складские остатки и финансовый срез. Закрытые активности и отметки защищены на уровне базы; отмена финансовых операций закрытого периода блокируется.

Непроданный дроп остаётся в общем складе, помечается периодом и показывается как полученный. Склад не распределяется по отдельным рейдам. Поздняя продажа такого остатка относится к архивному периоду; его зафиксированные веса используются для доплаты. Выплаты из архива используют тот же журнал и защиту от повторов. Исходный снимок не переписывается; свежий отчёт ниже включает последующие продажи и выплаты. JSON выгружает именно исходный снимок.

Казны текущего периода показывают его выручку минус выплаты/расходы; остатки прошлых периодов вынесены отдельно. Фактический общий баланс сохраняется и используется для проверки платёжеспособности. Закрытие не удаляет активности, деньги или склад. Пока текущий период закрыт 14-го, его казны показывают ноль; с 15-го учитываются новые операции.

Миграция 032 не закрывает существующие периоды автоматически и не проводит реальные выплаты. Период без подходящих получателей и с выручкой закрыть нельзя — требуется исправить состав. Первое закрытие включает ранее не архивированные складские остатки, имеющиеся к концу выбранного периода; повторно к другим архивам они не относятся.
