## F-01 — утверждён B0

2026-10-30: прямой ответ владельца «B0». Принято: Cormorant Garamond SemiBold для атмосферных заголовков и Golos Text для интерфейса. На доске B0 выделен и отмечен как выбранный. История вариантов сохранена; размеры и палитра этим выбором не утверждаются.

История первоначального сравнения:

- A: Golos Text для заголовков и интерфейса.
- B: Cormorant Garamond в крупных атмосферных заголовках + Golos Text в интерфейсе. Рекомендация.
- C: Manrope для заголовков и интерфейса.

На одинаковых образцах показаны кириллица, ники, формы, подписи кнопок и числа. Это отдельные варианты типографики, не варианты A/B старой HTML-концепции.

Перед окончательным выбором владелец отметил, что B нравится, и запросил дополнительные варианты на его основе. На доске «01b — Вариации направления B» представлены:

| Вариант | Заголовки | Характер |
|---|---|---|
| B0 | Cormorant Garamond SemiBold | Исходный B: тонкие, вытянутые формы |
| B1 | Prata Regular | Выразительные засечки, торжественный характер |
| B2 | Playfair Display SemiBold | Более насыщенные, контрастные заголовки |
| B3 | Lora Medium | Мягкие, округлые формы |

Интерфейс во всех четырёх вариантах — Golos Text. Одинаковые тексты, палитра, ширина и размеры: desktop 56/60, mobile 36/40, образец символов 24/32. Размеры служат сравнению; окончательную шкалу согласуем после выбора семейства. Мобильный блок шириной 320 px показывает обязательный ник и кнопку как фрагмент типографики, не полную форму регистрации. Оригинальная доска A/B/C сохранена.

Проверка сравнения: 108 дочерних узлов (74 TEXT, 30 FRAME, 4 INSTANCE), без изображений интерфейса; семейства всех текстов соответствуют выбранным вариантам, выходов текста за контейнеры нет. Полная доска просмотрена через скриншот Figma. Выбор B0 завершён.

## F-02 — утверждён S1

2026-10-30: владелец выбрал S1 в вопросе о масштабе и общей рабочей шкале. Приняты 56/60 desktop и 36/40 mobile с насыщенностью SemiBold 600, а также показанная шкала Golos Text. В Figma вариант отмечен как выбранный; S2 сохранён для истории.

На доске «01c — B0 · Размеры и иерархия» два варианта. В обоих сохранена насыщенность B0 — SemiBold (600). Обозначение размера: кегль / высота строки, px.

| Вариант | Desktop | Mobile | Характер |

| S1, выбран | 56/60 | 36/40 | Умеренный, сохраняет размер выбранного B0 |
| S2 | 72/76 | 44/48 | Более крупный заголовок, выше первый блок |

Принятая общая шкала Golos Text: заголовок страницы 28/36 desktop и 24/32 mobile, заголовок блока 20/28, текст и поля 16/24 Regular, кнопки 16/24 Medium, таблицы и пояснения 14/20 Regular. Насыщенность заголовков интерфейса — SemiBold. 12/18 допускается только для второстепенных меток; важные пояснения и ошибки от 14 px.

Показаны одинаковые тексты, два мобильных фрагмента шириной 320 px и шкала рабочих экранов. Это типографические образцы, не полная форма регистрации. F-02 завершён; текущий шаг — палитра.

Проверка: 85 дочерних узлов (57 TEXT, 26 FRAME, 2 INSTANCE); переполнений и несовпадений семейств нет. Фактические размеры и высоты строк S1/S2 соответствуют подписи; отсутствующих шрифтов нет. Полная доска просмотрена через скриншот Figma.

## Проверка и ограничения

Доски просмотрены через скриншоты Figma; проверены границы всех текстовых слоёв — выходов за родительские контейнеры нет. Исправлена автоматическая высота текста после изменения ширины. Шрифты доступны в Figma.

Перенос двух локальных картинок через upload_assets не выполнен: HTTP 403 на proxy CONNECT к mcp.figma.com. Настройки сети не обходились. Файл доступен через Figma connector; загрузка binary-ассетов требует восстановления поддерживаемого пути. Оригиналы в docs/concept/assets сохранены; в Figma только подписанные карточки их статуса, не фотографии. Текущему выбору шрифта это не мешает.

Состояние для продолжения: FIGMA_STATE.json; рабочая копия /tmp/design-system-state-xd-2026-10-30.json. В JSON хранятся возвращённые API file/session/node IDs, не секретные upload URLs. Сохранять тот же файл и сессию для продолжения задачи.
