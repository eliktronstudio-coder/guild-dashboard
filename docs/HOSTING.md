# Бесплатный запуск и совместимость

Проверено по официальной документации 2026-10-30. Это оценка осуществимости, не создание аккаунтов и не подтверждение фактического доступа из региона пользователей.

| Компонент | Предложение | Условия |
|---|---|---|
| Веб | Vercel Hobby, стандартный поддомен vercel.app | Личное некоммерческое использование, квоты; без гарантии непрерывной работы при исчерпании |
| Данные | Supabase Free PostgreSQL | 500 МБ БД; 1 ГБ файлов; 5 ГБ исходящего трафика; до двух активных free-проектов; возможна пауза после недели низкой активности |
| Auth | Supabase Auth + Telegram custom OIDC | Free допускает до трёх custom-провайдеров; совместимость конкретной конфигурации проверить end-to-end |
| Код | Личный GitHub-репозиторий, review и CI | Для связи с Vercel Hobby не планировать репозиторий организации; квоты CI проверить в аккаунте |
| Бот | Telegram Bot API, webhook в веб-приложении | Без постоянно работающего VPS; уведомления — этап 6 |
| Почта | Внешний SMTP, когда выбран | Встроенная тестовая почта Supabase не подходит для публичной регистрации; домен/провайдер могут потребовать затрат |

Оценка старта: **0 обязательных ежемесячных платежей** при Telegram-first, стандартном домене, небольшом объёме данных и соблюдении условий провайдеров. Это не обещание вечного бесплатного хостинга. Собственный домен, гарантированная доступность, большой трафик, расширенная почта или хранение могут стоить денег. Платные опции автоматически не подключать.

Next.js официально поддерживает App Router, TypeScript и Tailwind в стандартной установке; опубликованный минимум Node — 20.9. Выбирать актуальный поддерживаемый LTS, доступный в Vercel, и зафиксировать совместимый набор версий на этапе 1. В среде проектирования обнаружен Node 24.19.0; это не подтверждение сборки будущего Next.js-приложения.

## Эксплуатация

- Мониторить квоты до исчерпания; ограничивать размер аватаров и выгрузок, использовать пагинацию. Не генерировать искусственную активность для обхода пауз.
- Внешние сервисы должны быть доступны из региона гильдии и Telegram webview; это отдельная проверка перед запуском.
- Preview не получает production-секреты и данные. Production-миграции выполняются отдельно, с резервной копией.
- Free не считать заменой резервной копии. Предложение: зашифрованный ежедневный экспорт Postgres, отдельная копия объектов Storage, 7 дневных + 4 недельных; хранение в аккаунте владельца, периодический restore. Место хранения и квоты ещё не выбраны; резервирование не объявляется настроенным.
- До первого запуска проверить восстановление и rollback. CSV-экспорт для пользователя не равен полному backup Auth/БД/Storage.
- GitHub mobile: изменения через PR с описанием и результатами CI; deploy по согласованной ветке, откат на прошлую проверенную версию. Никаких ручных правок production с телефона.
