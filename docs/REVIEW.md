# Проверка этапа 0

Дата: 2026-10-30. Статус: материалы готовы к согласованию; этап 0 ещё требует выбора владельца.

## Подготовлено

- Шесть обязательных документов проекта и отдельные архитектура, дизайн, размещение, обзор текущей системы.
- Самодостаточный HTML-макет с двумя оформлениями и четырьмя экранами.
- Оригинальные SVG-эскизы знака XD и favicon; в концепции 02 фон заменён на созданные для проекта фотореалистичные изображения.
- PNG главной в двух направлениях, входа, регистрации, состава и мобильных вариантов.

## Проверено фактически

Chromium через Python Playwright; HTML загружен методом `set_content` (доступ file:// ограничен политикой браузера среды). Приложение Express и сервер Next.js не запускались.

- Переключение двух тем и четырёх экранов.
- Отображение четырёх экранов при ширинах 320, 390 и 768 px: нет горизонтального переполнения документа.
- Скриншоты desktop 1440 px и mobile 390 px; визуально просмотрены главная, регистрация и мобильный состав.
- Поиск без учёта регистра по демонстрационным никам; фильтрация ролей; пустое состояние.
- Пустой ник, ник из пробелов и отсутствие обязательных согласий не переводят макет в состояние ожидания.
- После корректного ввода показывается явно обозначенное демонстрационное ожидание; запросов на сервер нет.
- `prefers-reduced-motion: reduce` отключает CSS-переходы.
- Во время проверки ошибок JavaScript не обнаружено.
- Расчёт контраста базовых пар: основной текст/фон 13.52:1; вторичный текст/панель 7.47:1; белый/основная красная кнопка 7.20:1; золото/фон 7.76:1.

Это не полная проверка WCAG. Реальные Safari/Android, скринридер, все состояния компонентов и клавиатурные сценарии требуют отдельной приёмки этапа 1.

## Обнаружено и исправлено в макете

- Стрелка в выбранном системном шрифте отображалась отсутствующим глифом; заменена на поддерживаемую.
- Длинная подпись бренда переносилась в узкой панели; скорректирован размер подписи.

## Ограничения

Новая БД, серверная регистрация, проверка уникальности ников, авторизация, RLS, финансовые транзакции, SMTP, Telegram-интеграция и деплой не реализованы и не тестировались. В макете нет реальных пользовательских данных. Форма проверяет лишь демонстрационный ввод; это не реализация полной политики Unicode-ников. Вывод по бесплатному старту основан на документации провайдеров, не на нагрузочном тесте.

Расхождения существующего кода перечислены в BASELINE.md; они не исправлялись в рамках проектирования. Старые отслеживаемые исходники не изменены. `node_modules/` уже был неотслеживаемым до начала работы.

## Повторная проверка концепции 02 — 2026-10-30

Chromium / Playwright, автономный HTML через set_content; снимки получены с остановкой анимаций на время захвата. Проверены:

- Декодирование всех трёх отображаемых фоновых изображений и адаптивных вариантов.
- Наличие медленного движения 24 секунды на главной; выключатель полностью отключает эффекты.
- Native View Transitions и fallback при отсутствии API; быстрая последовательная навигация оставляет последний выбранный экран.
- Изменение prefers-reduced-motion во время работы: движение выключается, кнопка отражает ограничение устройства; возврат к обычному режиму работает.
- Четыре экрана на 320/390/768 px без горизонтального переполнения; поиск и обязательные поля формы сохранили поведение.
- В итоговом прогоне нет ошибок JavaScript и внешних HTTP(S)-запросов.
- Визуально просмотрены главная, вход и мобильная главная; PNG обновлены.

При проверке найдено необработанное отклонение ready-промиса отменённого перехода при быстрых переключениях; исправлено, повторный прогон прошёл. Убрана лишняя рамка программно сфокусированного заголовка, фокус интерактивных элементов сохранён. Положение кадра главной скорректировано, чтобы луна и верх тории оставались видимыми.

Это проверка макета, не замер FPS/энергопотребления реального телефона и не тест production-приложения. Реальные Safari/iOS/Android и показатели загрузки — этап 1. Архитектура и выбор A/B остаются на согласовании.
