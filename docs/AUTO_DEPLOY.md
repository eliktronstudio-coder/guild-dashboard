# Автоматический деплой Timeweb

Сервер каждые две минуты проверяет опубликованную ветку codex/xd-foundation-20261031. Изменения локальных файлов не публикуются автоматически. После git push новая версия собирается отдельным релизом через deploy-timeweb.sh; неуспешный старт возвращает прежний service. Проверки базы в deploy-timeweb.sh блокируют несовместимую установку. Миграции Supabase пока применяются отдельно до деплоя.

Однократное включение на VPS:

```bash
cd /var/www/xd-guild-command-center
git pull --ff-only origin codex/xd-foundation-20261031
bash scripts/install-auto-deploy-timeweb.sh
```

Установка помечает текущий commit как исходный и не запускает первый деплой. Следующая публикация запускает обновление. Неудачный релиз повторно проверяется через две минуты. Одновременные запуски запрещены flock. Локальные изменения и расхождение веток останавливают обновление.

Состояние: `systemctl status xd-guild-deploy.timer`. Журнал: `journalctl -u xd-guild-deploy -n 60 --no-pager`. Отключение: `systemctl disable --now xd-guild-deploy.timer`.

Включение на рабочем VPS из среды агента не выполнено; требуется однократный запуск установщика на сервере.
